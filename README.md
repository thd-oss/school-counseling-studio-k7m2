# 학교상담과 생활지도 (상권) · 인터랙티브 학습 스튜디오

『학교상담과 생활지도 (상권: 01~06장)』의 핵심 이론과 현장 사례를 체계적으로 복습하고, 객관식 및 실상황 대입 논술형 문항을 반복 훈련하기 위한 정적 인터랙티브 학습 웹 애플리케이션입니다.

## 주요 학습 기능

1. **스크롤 기반 핵심 요약 & 인터랙티브 도식화 (Mode 1)**
   - 장별 3계층(Layer 1 핵심 요약 · Layer 2 구조화 벤토 카드 · Layer 3 원고 세부 탐구) 구성
   - 01~06장별 인터랙티브 개념 도식 및 시뮬레이션 뷰 제공
   - 스크롤 및 절 단위 읽기 진도 자동 추적 (`localStorage` 자동 저장)

2. **객관식 문제 풀이 & 회차 전환 (Mode 2)**
   - 기본 수록 35문항 + 제미나이(`.txt` / `.json`) 문제팩 불러오기 지원
   - 회차별 문제팩 전환, 즉시 채점 및 해설 확인, 오답·진도 기록

3. **실상황 대입 논술형 해결 & 채점 루브릭 자가진단 (Mode 3)**
   - 기본 단답·서술형(30문항) 및 실상황 사례 적용 논술 문항 연습
   - 자가진단 채점 루브릭 체크리스트와 모범 답안 비교, 초안 자동 저장

4. **진도표 대시보드 & 기록 백업**
   - 상권 01~06장 38개 절의 전체 진도 현황 한눈에 확인
   - JSON 내보내기/가져오기 백업 및 다크 모드 지원

## 제미나이(Gemini) `.txt` 문제팩 업로드 규격

상단 `[문제팩 불러오기 (＋)]`에서 `.txt` 파일을 업로드하거나 텍스트를 직접 붙여넣어 새로운 문제 회차를 추가할 수 있습니다. (예시 파일: `sample_gemini_pack_vol1.txt`)

- `[SET]` 헤더: `제목:`, `설명:` 등으로 세트 정보 정의
- `[MCQ]` 블록: 객관식 문항 (`번호:`, `장:`, `문항:`, `보기1:`~`보기5:`, `정답:`, `해설:`)
- `[ESSAY]` 블록: 실상황 대입 논술/단답 문항 (`번호:`, `장:`, `유형:`, `상황:`, `문항:`, `핵심키워드:`, `채점기준:`, `모범답안:`)

- **소스 수정 후 재빌드**:
  ```bash

  ```
